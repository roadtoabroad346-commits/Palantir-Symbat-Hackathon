# Как открыть все MVP и 3D-глобус

## В этой облачной среде

Демоцентр уже запущен. Откройте Chrome внутри облачного Desktop и введите:

```text
http://127.0.0.1:3000
```

На стартовой странице нажмите **Открыть 3D-глобус** или выберите любой MVP. Все приложения открываются в одном окне. Кнопка **Все MVP** возвращает к списку. Регистрация не нужна: демороль выбирается автоматически.

## На своём компьютере

1. Распакуйте архив в отдельную папку.
2. Установите Node.js24 и pnpm11.25.0, если их ещё нет. Команда установки pnpm: `npm install -g pnpm@11.25.0`.
3. Windows: откройте `START_DEMO.cmd`. macOS: откройте `START_DEMO.command`. Они установят зависимости при первом запуске, запустят демоцентр и откроют браузер.

Можно запустить из терминала в папке проекта:

```sh
pnpm install --frozen-lockfile
pnpm demo
```

На своём компьютере используйте адрес `http://localhost:3000`. Оставьте терминал работающим, пока проверяете демо. При запуске дождитесь статуса **Готово**; все базы и демонстрационные данные подготовятся автоматически. Ctrl-C останавливает запущенные демоцентром приложения.

Адрес облачной среды не является публичной интернет-ссылкой: `localhost` в браузере вашего компьютера открывает ваш компьютер. Для просмотра без запуска локально используйте облачный Desktop.

## Что попробовать

- **3D-глобус:** Play под глобусом → страна → отзывы. P — презентация, T — таблица.
- **Growth Engine:** создайте кампанию → симуляция → аналитика и CSV.
- **Амбассадоры:** задание → переключите роль на admin → одобрите → награда.
- **Челленджи:** команда → симуляция → роль judge → оценка.
- **Школьный портал:** класс → импорт никнеймов → симуляция → отчёт.
- **Школьная лига:** код START-001 → карточка основателя → публикация → PNG.

Все данные вымышлены. Реальная AI Startify не подключена. Интернет нужен для первоначальной установки пакетов; демонстрации используют локальные данные.
