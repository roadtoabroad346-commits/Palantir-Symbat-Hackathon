# Learning program

Founder studio `/v2`: Today, Project, Learning, Prototype, SIGNAL, Experts, Bookings, Results and Settings. Only four primary mobile destinations are shown; others use More tools. An individual does not need a school or team.

The first trial saves an observation before requiring an institutional profile. Eight mission records cover trial, research, mini brief, prototype, user test, change, pilot plan and portfolio. Each mission has a goal, benefit through the concrete action, time, example, completion criterion and next step. All submissions are persisted with source/limitations; the rule-based feedback is explicitly not proof of an external action.

Institution programs: trial 45 minutes, bootcamp 2×45 minutes, 4-week residency and club. Suggested residency rhythm is two 45-minute sessions per week: problem/research, prototype, test/change, pilot/continuation. Teachers can respond to scoped help requests. Baseline help is not gated on score or credit balance.

SIGNAL has hypothesis, target, role/language/age screening, task, format and deadline. Voluntary tester profiles must match screening. Raw responses, task outcome and difficulty remain beside the cited manual summary. Decisions include changing the hypothesis/audience, gathering more data, continuing or stopping. Negative results do not block a next project step; small samples remain preliminary.

Portfolios link actual local saved materials and are demo documents, not official certificates. Participants can continue, change hypothesis, test others, pause or finish. Reminder preference is stored in-app; email/push delivery is not connected.
