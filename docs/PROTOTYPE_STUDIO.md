# Prototype studio

Routes: no-code, guided prompt, own existing application. The mini brief records user, task, actions, data, constraints, errors and acceptance. The learner sees labelled fields, not JSON instructions. One change creates a saved version and prompt scaffold.

Human checks record expected, observed and reproduction steps for seven cases: main path, empty input, invalid input, save, reopen, unavailable dependency and recovery. All must pass for the recorded check to pass. These are human attestations; this release does not claim to execute/test the learner's external application automatically.

Bugs preserve expected/observed behavior, reproduction, error and last change. Resolution needs a later passing check for the same project and records the fix. External prototype URLs are HTTP(S); no untrusted code is executed or embedded in a privileged hub page.

The AI Startify garage, code generation and sandbox providers are not connected. Safe local learning and linking one's own prototype remain available. A sandbox origin/limits must be established before enabling arbitrary code execution.
